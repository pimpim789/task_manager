function formatTitle($text, $maxLength = 20) {
    if (mb_strlen($text, 'UTF-8') > $maxLength) {
        return mb_substr($text, 0, $maxLength, 'UTF-8') . "...";
    }
    return $text;
}

function getCurrentGreeting() {
    $hour = (int)date('H');

    if ($hour >= 6 && $hour <= 11) {
        return "Доброго ранку";
    } elseif ($hour >= 12 && $hour <= 17) {
        return "Добрий день";
    } elseif ($hour >= 18 && $hour <= 23) {

}

Поясніть принцип “DRY” (Don’t Repeat Yourself) та як власні функції допомагають його дотримуватись.

Принцип DRY закликає уникати дублювання коду. Власні функції дозволяють винести повторювальну логіку в один бллок і викликати її в багатьох місцях, спрощуючи підтримку й редагування програми.

Що таке аргументи функції та що таке параметри за замовчуванням? Наведіть приклад з коду.

Аргументи це змінні, які функція приймає для обробки під час виклику.
Параметри за замовчуванням це значення, які використовуються автоматично, якщо аргумент не було передано при виклику.
прклад з коду: function formatTitle($text, $maxLength = 20), $text - це обов'язковий аргумент, а $maxLength = 20 - параметр за замовчуванням.

Що станеться, якщо у функції не написати конструкцію return, але спробувати присвоїти результат її виклику в змінну x ($x = myFunc())? Яке значення буде в $x?

Якщо у функції немає return, функція за замовчуванням повертає null. Відповідно, змінна $x отримаж значення null.

Що таке “область видимості” (scope) змінної? Чи можна у тілі функції звернутись до $taskTitle, створеної за межами цієї функції, без ключового слова global?

Область видимості - це зона зона доступності змінної. Змінні ззовні функції є глобальними і недоступні всередині неї юез ключового слова global або передачі через аргументи.

Для чого призначена вбудована функція substr() і які вона умовно приймає аргументи?

Функція substr() призначена для вирізання та повернення підрядка із заданого рядка.
Вона приймає аргументи: substr(string $string, int $offset, ?int $length = null), де $string — початковий рядок, $offset — позиція початку вирізання, $length — довжина фрагмента.
