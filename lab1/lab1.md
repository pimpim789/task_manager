Яке призначення вебсервера (наприклад, Apache) у процесі веброзробки?

Вебсерсвер приймає запити від браузера, обробляє їх, звертається до файлів чи баз даних та повертає результат у браузер у вигляді вебсторінки.

Яким розширенням файлу повинен володіти скрипт, щоб сервер обробив його як PHP-код?

Файл повинен мати розширення .php.

Чому PHP-файл потрібно відкривати через браузер за адресою localhost, а не просто подвійним кліком миші у файловому менеджері?

Тому що php - це  мова, яка виконується на сервері. подвійний клік відкриває файл убраузері як html або текст, при цьому php код залиться не обробленим, бо на ком'юютера немає програми яка б прочитала його. 

За що відповідає конструкція echo у PHP?

Echo використовється для виведення даних.

Яку інформацію виводить функція phpinfo() і для чого вона може знадобитись?

Ця функція виводить детальну системну інформацію про поточний стан php. Вона потрібна розробникам для діагностики, перевірки правильностіі налаштування середовища або сумісності з різними бібліотеками.
